About

NeoApps is a set of Windows apps by Josef Familonidis. The site is unlisted — share the link only with people you trust.

How do I install an app?

Download the zip, extract it to a folder you can write to (for example C:\Apps, not Program Files), and run the .exe. There is no installer. Most apps need the .NET 8 Desktop Runtime (x64). If it is missing, Windows will offer a download link.

Windows says “Windows protected your PC”

These apps are not code-signed, so Windows SmartScreen may warn the first time you run one. That is expected.

Click More info, then Run anyway.

Are the apps portable?

Yes. They ship as portable zip files with no installer. Settings are saved next to the app or in your user folder.

What is the .NET 8 Desktop Runtime?

A free Microsoft component that these apps use to run. Install the x64 Desktop Runtime from dotnet.microsoft.com if Windows asks for it. The SDK is not required.
